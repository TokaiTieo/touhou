# 真实记录的定性复核

这是 Codex 对已保存合成案例的阅读分析，不是玩家盲测或人工评委分数。原始记录在 `report.json`，自动汇总在 `summary.md`。没有另发评审模型请求。

## 当前结论

**保留原模式为默认，协作模式作为可选测试功能。** 权限、人物决定和正式状态的工程隔离更明确，但现有证据不足以证明协作模式全面改善人物口吻、剧情连贯、自由行动或关系自然度。

| 维度 | 已观察到的证据 | 仍有的问题 |
| --- | --- | --- |
| 人物口吻 | `fixed-structured-v2:*:2:one` 中三种模式均有可辨认的灵梦口吻；独立 NPC 发言可单独审查 | 不能仅凭一次正确口吻证明长期稳定；多人同场容易产生格式相似的答复 |
| 事实承接 | 同组案例都回应了整理旧符札的约定；协作原话带明确 actor ID | 夹具开局为早晨，主持人仍出现“午后”描写，检索不等于事实一致性证明 |
| 行动自由 | `ordinary_friendship` 中本人回应接受普通朋友关系；没有强制恋爱或地图解锁条件 | 协作只把已支持的领域命令和规则活动落实为状态；任意自然语言新地点/任务变化未全面等价于原流程 |
| 节奏 | NPC 本人回应与旁白分开，有助于识别谁作决定 | 60回合平均等待原模式5.33秒、检索12.55秒、协作13.88秒；这是同时运行的本机端到端测量，含排队，不可直接当服务商推理速度对比 |
| 关系自然度 | `fixed-structured-v2:collaborative:9:ordinary_friendship` 中爱丽丝原话保持朋友边界 | 旁白擅自补写爱丽丝转身返回森林；结构状态没有因此移动，文本与规则仍可能脱节 |
| 私密隔离 | 私密口令没有进入本次未授权 NPC 请求；定向分段、后续记忆、同名与分支单测通过 | 一个口令夹具不是完整信息流证明；仍需更多非关键词式泄漏、推断与长期剧情样本 |

## 长测中暴露的故障

- 首轮24回合：原流程24/24、检索24/24、协作22/24。一次`relationship`提案附带禁止字段，随后对模型公开了按动作区分的精确schema；另一次原始speak JSON可正常重放，缺少原始错误链，不能断言原因或宣称已修复。
- 首轮60回合：原流程60/60、检索60/60、协作58/60。一次`database is locked`，一次赫卡提亚输出了禁止的`binding`和`game_hour`顶层字段。后者正确阻止了提交，不能为提高成功率而放宽身份写入。
- 检查发现隔离评测跳过Functional checkpoint时，测试数据库仍用DELETE journal；正式Functional运行使用WAL。已让评测对齐WAL并增加脚本指纹、错误栈，原60轮结果保留，不改写为新配置结果。WAL降低读写争用，不是所有锁问题的绝对保证。
- 对齐WAL后的24协作复测23/24通过，未重现数据库锁；一次无NPC回合的主持人引用旧事件被严格拒绝，补齐了无公开事件时`cited_event_ids.maxItems=0`。修正后复测单独标为`24-final-citations`，不覆盖原记录。
- `24-final-citations`最终24/24通过，没有再发真实调用。这个微调后的24轮不能替代一份未重新执行的60轮结果；最终合计582请求，已报告3,176,604 Token，含未知保守值3,234,112 Token。
- 初始固定评测曾出现思考占用短输出预算、空JSON、截断及服务并发容量问题。供应商结构化参数和全局评测并发上限修正后，`fixed-structured-v2`三模式27/27通过；发布版WAL固定复测再次27/27通过。此前失败和消耗仍计入总账。
