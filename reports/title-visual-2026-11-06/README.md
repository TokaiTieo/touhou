# 标题页：神社封面与存档手札

## 从印象图到界面

按用户要求先使用内置 image_gen 生成标题页印象图，再生成独立的参道背景和透明书法标题，最后实现为真实 Vue 页面。方向为“红白神社、清透雅致”，不是只更换旧横幅，也不将完整概念图铺成假界面。

- `title-before.png`：修改前标题页。
- `title-concept-v1.png`：本轮标题页印象图。
- `../../static/ui/title-shrine-approach-v1.png`：新增参道、鸟居与神社插画。
- `../../static/ui/title-calligraphy-v1.png`：新增透明《东方异变录》书法题字，保留真实 H1 文本及高对比度文字替代。
- `prompts.json`：完整提示词、选用素材和图标来源。
- `title-mark-check.png`：书法素材在白底浏览器中的透明效果核对图。

复用上一轮的结绳纸垂与花枝素材。移除重复第二层顶栏，将原有 API 设置与测试连接入口移入封面角落。创建、导入命令移到存档上方；存档使用带编号签牌的三列手札，中屏双列、手机单列。继续、时序、导出、转为 NPC、删除的原有处理函数未改。

题字为装饰图片，存档名称、资料、按钮均是实际 DOM。没有把印象图中的雾月、清和示例人物写入用户存档，也没有新建付费模型调用。

## 样式边界

标题页集中由 `css/components/title-screen.css` 负责；从 `css/app.css` 和 `css/vue-game.css` 移除 101 个旧标题页选择器，保留共享控件和游戏内规则。CSS 检查新增标题组件归属约束，防止再次堆叠覆盖链。

九个 [Lucide 官方图标](https://github.com/lucide-icons/lucide) 保存在 `static/ui/lucide/`，随附完整 [许可声明](https://lucide.dev/license)，无运行时 CDN 依赖。删除使用图标按钮；其他辅助命令保留文字及悬停提示。未更改顶栏、桌面 EXE 的既有品牌图标。
