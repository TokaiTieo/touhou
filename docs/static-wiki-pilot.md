# 静态设定 Wiki 试点

v0.18.0 / V14；只做公开静态设定。开发者审核目录与游戏资源分开，默认关闭。按 2026-11-20 的决定，当前工作区只有草稿，无正式发布指针。分支剧情 Wiki、私人知识页、后台更新与 LLM 编译不在本版。

## 来源和获知条件

12 页：4 名人物（灵梦、早苗、咲夜、蕾米莉亚）、3 个地点（博丽神社、守矢神社、红魔馆）、2 个势力、3 项规则。试点名单不参与调度。所有事实均是公开项目设定，不宣称与官方正典完全等同。

| 来源 | 唯一可编译字段 | 用途 |
| --- | --- | --- |
| 人物名册 | name、profile.identity、location_id | 本人设定身份，关联地点不等于当前行踪 |
| 基础地点 | name、description | 地点名称与介绍 |
| 世界书 | title、content | 经选定的地点补充、势力分工、规则 |

源表按稳定 ID 定位，不按数组下标。不能将通用 profile、人物记忆、自由文本存档或任意相对路径加入输入。标记私有、未确认、撤回、跨时间线等来源不能通过试点编译。每条事实携带出处 ID，版本包内可查到字段路径、值与 SHA-256。人物与地点映射、来源 ID 唯一性和固定标题由程序校验；跨资料的自然语言矛盾仍需人工判断。

世界设定可由开发者阅读，不代表所有角色都知道。读取规则由代码定义：公共规则可读；身份或地点知识按指定人物或当前场景；势力内部职责限列出的成员与主持人；外来者叙事规则仅主持人。链接的目的页也必须可读，否则整条关联不返回。未创建私有来源。旧世界书已有的公开信息不会因这个试点被追溯改成秘密。

## 编辑工作流

在项目根目录用项目 Python 执行。以下是开发者操作示例，不代表当前已经发布：

```powershell
python scripts/static-wiki.py scan
python scripts/static-wiki.py draft
python scripts/static-wiki.py validate
python scripts/static-wiki.py diff
# 逐条复核 reports/static-wiki-pilot/draft.json 和 pages/ 后：
python scripts/static-wiki.py publish --hash <完整草稿哈希> --reviewer <审核人>
python scripts/static-wiki.py withdraw --hash <已发布版本>
python scripts/static-wiki.py withdraw-source --source book:wi_faction_moriya:content
```

draft 重建工作草稿及 Markdown。可以在草稿中删减冗余事实、将正文缩短为有出处的原文摘录；需要改写原始设定时先修订权威来源，再重建。删减后以 JSON 和 validate 输出的新哈希审核，旧预览不能作为新草稿批准依据。diff 能对比已失效的上次发布正文，运行时不能使用这种编辑视图。哈希绑定版本，不是签名或本地恶意篡改防护。

发布在写锁内核对来源、允许字段、关联和草稿哈希，先生成不可变目录，最后原子切换发布指针。失败不会把未完成版本设为可读。可用较早的仍有效草稿重新发布来回退；已撤回版本禁止重新发布。撤回单一来源会使所有引用它的已发布版本失效；修订来源并重审后可发新版。打包导出只取当前已审核 JSON、12 页 Markdown 与必要撤回信息，草稿、历史包、写锁、评测日志、账本不随包分发。

## 游戏接入

开发者在启动前设置环境变量 `TOUHOU_STATIC_WIKI=1`（也支持本地 .env），重启服务后生效；未设置或为 0 即关闭。不修改 API Key、不写入角色存档。仅 `retrieval` 与 `collaborative` 使用此入口，legacy 不变；未发布时开启也不能读取草稿。

唯一入口是现有 `search_world_info`，默认混合检索；传 `source="world_book"` 可查原始细节，不能更换身份或跳过权限。世界知识使用原有 1,800 字符分配，全上下文仍为 15,000 字符；这不是固定 Token 数。游戏不为 Wiki 新增模型调用。查询不发起剧情更新或激活 NPC。

账本按存档、epoch、回合范围固定首次看到的版本（包含无版本），只存执行元数据。普通发布只影响新回合；源字段哈希、读取条件、撤回或审核状态变化优先于冻结。上下文组装、模型子任务和最终结算检查旧证据；失效则停止旧回合，由手动恢复重建指纹，旧费用不退。不可追回已发给供应商的请求。首版宁可整包回退，也不在同一回合拼凑新旧页面。

M0–M3 验证、真实 A/B 的费用和限制见 [试点报告](../reports/static-wiki-pilot/README.md)。真人发布审核待定；未改存档结构、未重打包 EXE/ZIP。
