# V0.16 回合恢复与发布检查

## 兼容边界

- 存档格式仍为 V11；V1-V10 沿用现有增量迁移、原始备份和未知字段保留机制，不批量改写已有存档。
- 新客户端传 `record_history: true`，玩家行动、回复、角色状态、任务和幂等回执使用同一事务提交。旧客户端不传该字段时仍使用原有追加消息接口。
- 恋爱资料、身材、自定义人物和自由探索不变，没有新增长度或文件大小准入限制。

## 回合中断

- 发出请求前将当前行动及同一个 `turn_id` 暂存在浏览器本地；加载角色只查询状态，不自动发起付费生成。
- “恢复回合”复用原请求与回合标识。已提交回合直接返回原回执，不再次推进时间或结算；失败且没有可复用结果时可能重新调用模型，需要玩家主动点击。
- “确认停止”以服务器结果为准，进入结算/检查点清理阶段不再中断；网络失败时保留未确认记录供查询。
- 本地待恢复记录包含剧情文字，不含 API Key。完成/确认取消后清除；浏览器清理数据或换浏览器可能失去本地待恢复提示，但已提交剧情仍以服务端存档为准。

## 长历史与存档健康

- `_history` 是正式剧情数据，必须随存档备份，不能清理。健康检查逐块验证可读性、哈希及条目数；只有依赖完整且格式可用的快照可恢复。
- `_history_search_v1.sqlite3` 是可重建检索缓存，不是剧情源文件；首次搜索建立索引，后续只刷新变化的分块。缓存不可用时回退原扫描，文件缺失或损坏不会当作空剧情跳过。
- 内存中的文本特征缓存最多 8192 项，返回独立副本，修改记忆原文会自动使用新特征。

## 质量复核

- 制作人隔离评测增加承诺、秘密隔离、普通相处及礼物后续场景，保留行动与回复原文。
- 自动结果仅为关键词/重复度等启发式检查，不能证明人设、感情或因果完全正确；人工按人物口吻、事实承接、行动自由、节奏、关系自然度分别评分。
- 人工评分不覆盖自动分数，保存后重新打开控制台可继续复核，支持导出 JSON。评测报告含原文，分享前应自行审阅。
- 自动测试只用模拟模型；真实 24/60 回合质量仍需主动设置预算并运行，再结合人工复核。

## 样式与发布

- `css/components/` 分别持有消息、输入区、侧栏、顶栏与主题变量；应用基础布局在 `app.css`，页面与其余主题样式在 `vue-game.css`。`npm run check:css` 检查导入、语法和高频组件归属。
- `scripts/release.ps1 -Mode Status` 为只读状态检查；`Exe` 和 `Package` 运行完整验证后发布。候选 ZIP 先解压冒烟，再替换正式 ZIP；失败候选清理，正式旧包保留。
- 未验证的文件不能只凭版本号视为最新版。源码更新后，之前通过冒烟的旧 EXE/ZIP 会标为 `outdated`，修改过却没有新验证回执的文件标为 `unverified`。
